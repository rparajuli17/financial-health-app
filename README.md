# Financial Health App

A weekly personal financial-health app, built from scratch: see what you earned vs. spent this week, get specific recommendations on where spending can be reduced, and track your salary against target allocations for investing, emergency fund, trips/travel, and discretionary spending.

**Authentication is a first-class feature:** password at signup, passkey enrollment on first login (private key stays on-device), and biometric identity verification (Entrust ATO) guarding account recovery and new-device passkey rebinding.

**Status:** Phase 0 — design. See [ONE_PAGER.md](ONE_PAGER.md) for the full plan: features, auth flow, the allocation and recommendations engines, and the 12-step build sequence.
